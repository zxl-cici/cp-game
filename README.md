# 红绳懒得系，弹珠自己撞

选择名著角色当母球，撞出 AI 姻缘档案。

## 简介

一款基于 Next.js 的静态互动页面，融合古典名著角色与 AI 生成故事。用户选择角色，触发 AI 生成趣味"CP 姻缘"档案。

## 技术

- **框架**: Next.js (静态导出)
- **AI 接口**: API Route 生成故事
- **部署**: 纯静态文件，可直接托管于任意 Web 服务器

## 本地运行

```bash
# 方式一：直接打开
# 用浏览器打开 index.html 即可

# 方式二：使用任意 HTTP 服务器
npx serve .
```

## 部署

将全部文件上传至静态托管服务即可，如 GitHub Pages、Vercel、Netlify 等。
